📖 Quick Start Guide
⚡ Get running in 5 minutes
1
Get your Session ID
Head to the Session Generator and pair your WhatsApp number. Copy the SESSION_ID you receive.
2
Fork or download the repo
Fork Tennor-modz/trashcore-ultra on GitHub, or download the ZIP above. You need a GitHub account for one-click deploys.
3
Pick a platform & deploy
Click any platform button above. Railway and Heroku support one-click deploys straight from your fork. For others, upload the source manually and install dependencies with npm install.
4
Set environment variables
Add your SESSION_ID as an environment variable on your platform's dashboard. Check the repo README for all required env vars.
5
Start the bot 🎉
Deploy and your bot goes live. If you hit any issues, join the Telegram group or DM @trashcoredev2 for help.
